🔐 Week 3 – Password Security and Hash Analysis

Network Walks Internship | Batch B084

📌 Project Overview

As part of Week 3 of the Network Walks Internship, I explored password security, password hashing, and hash analysis using John the Ripper and the Network Walks Hash Calculator.

The practical exercise focused on understanding how password hashes work and how password auditing tools can help identify weak passwords in an authorised testing environment.

🛠️ Tools Used

1. John the Ripper

- A password security auditing tool.
- Used to assess password strength through authorised hash auditing.
- Helps demonstrate the risks associated with weak passwords.

2. Network Walks Hash Calculator

- Used to generate and analyse password hashes.
- Helped me understand how passwords are represented through hashing algorithms.
- Provided practical exposure to hash identification and analysis.

🎯 Learning Objectives

Through this exercise, I gained practical knowledge of:

- Understanding password hashing.
- Identifying different hash formats.
- Understanding password security vulnerabilities.
- Exploring password auditing techniques.
- Recognising the importance of strong passwords.
- Understanding how cybersecurity professionals assess password security.

💡 Key Takeaways

This exercise helped me understand the importance of password security and the role of password auditing in cybersecurity.

I also learned that weak passwords can expose systems to security risks, making strong password policies and secure authentication practices essential.

⚖️ Ethical Considerations

All activities were conducted for educational purposes within an authorised learning environment. Password auditing should only be performed on systems and hashes for which permission has been granted.
